реализации; независимой оценки криптографической стойкости пока нет.

## Переход на исправленную версию

1. Проверить PR и дождаться успешных проверок CI. Слияние и развёртывание —
   отдельные действия; текущие изменения их не выполняют.
2. Сохранить резервные копии старых файлов и ключей. N2QF v1 больше не принимается:
   достоверность старых данных можно подтвердить только независимой доверенной
   длиной/хэшем/подписью, затем зашифровать проверенный текст в v2.
3. Обновить вызывающий код с учётом новых сигнатур C и результатов ошибок
   Rust/Go; убрать предположение о детерминированности всего файла.
4. Пересобрать WASM из исходников и развернуть комплект HTML/CSS/JS/worker/pkg
   одной версии. Проверить реальные заголовки HTTPS-хостинга.
5. Не переводить систему на реальные секреты до независимой экспертизы и
   устранения её замечаний. Прохождение тестов не подтверждает заявленные
   128/256 бит стойкости авторского алгоритма.
