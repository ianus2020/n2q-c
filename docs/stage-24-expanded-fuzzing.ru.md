## Версия, среда и параметры

Исходный коммит: `8f8b23ae00d2cd2923ea3aa34352d9db3481bb9e`.
Все 72 хэша source manifest сверены с Git blobs именно этой версии; SHA из
глобального заголовка git archive тоже совпадает. Внутренний Git checkout
контейнера имеет отдельный synthetic SHA, явно записанный в summary.

Linux aarch64, Debian Clang 14.0.6 + compiler-rt, Rust
1.101.0-nightly (8006091eb, nightly-2026-10-18), cargo-fuzz 0.13.2.
Базовый образ и SHA архива сохранены в environment.json. Дополнительно
установленные пакеты не делают сборку образа полностью воспроизводимой.
Контейнер ограничен 2 CPU / 2 GiB, без host binds и опубликованных портов;
сеть отключена, Cargo offline. Использовались только синтетические данные
и публичные fixture keys. Реальные файлы, ключи и локальный HTTPS-стенд
в кампанию не передавались.

Команда из [инструкции](../fuzz/README.md):

```sh
CARGO_NET_OFFLINE=true CARGO_TARGET_DIR=/audit/target \
  N2Q_SOURCE_COMMIT=<полный SHA проверяемого коммита> \
  python3 scripts/fuzz-campaign.py --output /audit/expanded24 \
    --runs 1000000 --seconds 180
```

Seed 20261019; вход до 4096 байт, лимит отдельного входа 5 секунд,
RSS лимит процесса 512 MiB. Перед C-целями пройдены clean/UB/UAF controls;
все C sanitizer findings завершают процесс ошибкой. Исходный corpus пустой,

Четыре цели остановились по времени до заданного миллиона. В логе libFuzzer
их время округлено до 181 секунды. Таблица содержит фактические счётчики,
а не сумму запрошенных бюджетов. Coverage edges зависят от инструментации
и не являются процентом всех путей программы.

`modes_roundtrip` завершил 32 497 полных наборов свойств во всех 8 вариантах
(128/256, 8/16 раундов, SIV/stream). `convergent` завершил 8872 набора в обоих
профилях. Каждый набор включает успешную аутентификацию созданного сообщения,
его повреждение и проверку отказа/очистки/canaries; convergent дополнительно
проверяет детерминизм и некорректные capacities/длины. Эти счётчики входят в
число выполнений и не прибавляются к нему. Остальные цели включают множество
быстрых отказов parser/authentication; это не миллионы независимых атак.

## CI и сохранённые подтверждения

[CI 39301378234](https://github.com/ianus2020/n2q-c/actions/runs/39301378234)
для `8f8b23a` завершил все семь заданий SUCCESS: native, web, fuzz,
dependencies, cryptanalysis, anchor, migration. В том числе пройдены
native/6-port interop, браузерные проверки HTTPS, anchor и synthetic migration.
Сохранены jobs/full log, fuzz artifact и dependency reports. Последующие
документальные коммиты не изменяют тестировавшиеся implementation/harness files.

Два одинаковых scanner alerts в CI manifests оказались SHA-256 исходника
`migration_keys.rs`, а не credentials: все input hashes сверены с Git blobs.
Оригинальные JSON сохранены gzip с исходным byte hash; читаемые manifests
представляют map в виде path/sha256 records. Разбор и результат проверки —
artifact-review.json; исключений для сканера не добавляли.

[Полный evidence](audit/2026-10-19-fuzz-expanded/): summary, gzip log,
final corpus, environment, source hashes, CI и SHA256SUMS. До удаления
временного контейнера файлы скопированы на хост и сверены с коммитом.

В этой кампании новых ошибок реализации шифра не обнаружено. Ограничения:
не все входы/размеры/порты/ключи перебраны, аппаратные side channels и
многочасовые кампании этим запуском не закрыты. Независимая криптоэкспертиза,
отдельный эксплуатационный rollback domain CoNe, миграция реальных данных
и реальные инфраструктурные испытания остаются открытыми.
