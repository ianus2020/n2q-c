# Этап 14 — инструменты явной offline-миграции

Добавлены inventory/recovery/rekey CLI и отдельный Rust helper для новых
Argon2id-ключей, восстановления по параметрам и ограниченного legacy PW recovery.
Справка и точные ограничения — tools/migration/README.md.

Обычные читатели не принимают v1. Восстановление старого формата включается
отдельным флагом и требует независимые доверенные SHA256 исходного контейнера,
исходного plaintext и его размер. Inventory печатает только наблюдаемые хэши,
не объявляя их доверенными. Параметры отсутствующего старого KDF не угадываются.

Мигратор принимает raw/private JSON key files, не печатает ключи, не сохраняет
plaintext на диск и не меняет источник. Публикует private v2 Secure bundle после
всех проверок и read-back. No-replace rename сохраняет даже появившийся в гонке
существующий destination. В metadata попадают public salt/costs, но не ключ.
Legacy PW допускается только как явно выбранная операция восстановления;
его ключевой bundle запрещён для нового результата.

Локально восемь Python-тестов и два Rust-теста PASS: оба размера/профиля,
пустой v1, v2 rekey, усечения/склейки/повреждения/неверные размеры, неверные
доверенные данные, приватность key files, ошибка публикации и concurrent target,
Argon2id new/restore, old PW и отказ перезаписать ключевой файл. Legacy-векторы
получены отдельным запуском неизменённого pw.rs из коммита 771c1a5.

Реальных данных, паролей или ключей пользователя не использовано. Доверенная
инвентаризация реального архива, backup/restore и перенос реальных данных не
выполнены. Никакой автоматический перенос или развёртывание не запускается.
