# Этап 31 — закрытие SQLite при ошибках настройки соединения

В `Store.connect()` подтверждён путь ошибки без явного закрытия SQLite:
исключение при настройке `synchronous`, `fullfsync` или чтении `journal_mode`
возникало до передачи соединения коду, который отвечает за его закрытие.
Освобождение ресурса зависело от последующей очистки Python.

Настройка теперь заключена в блок, который закрывает соединение при любом
исключении и повторно передаёт ошибку вызывающему коду. Успешное соединение
остаётся открытым до явного закрытия владельцем. Отказ при режиме без WAL
также проверен: такой дескриптор закрывается.

Отдельно исправлено освобождение соединения, которое интеграционный тест
использовал для чтения `last_index`: транзакционный context manager SQLite
заменён на `contextlib.closing`. Именно тестовое чтение могло выдавать
наблюдавшееся предупреждение `unclosed database`; runtime-путь ошибки выше
подтверждён отдельными контролируемыми отказами.

## Проверки

- На прежнем `Store.connect()` тест не прошёл в трёх subtests: для каждого
  отказа PRAGMA отслеживаемое реальное SQLite-соединение оставалось открытым.
  Контроль сам закрывал соединения после проверки.
- После исправления три теста управления соединением PASS на Python 3.14.8
  и 3.9.6. Они используют временную синтетическую БД и контролируемое
  `sqlite3.OperationalError`; реальные сбои диска не моделировались.
- Все девять anchor-тестов PASS, включая существующие mTLS/C signer,
  concurrency/restart, потерянный ответ, откат signer и отсутствующий backend.
- Полный набор Python-регрессий: 63 теста PASS. Существующее предупреждение
  очистки HTTPError в `test_local_web` сохранено в журнале, не подавлялось.
- CI verification manifest включает исходный файл anchor-тестов.

[Evidence](audit/2026-10-20-anchor-connection-cleanup/) содержит журналы до/после,
хэши исходных файлов и SHA256SUMS. Действия выполнялись на временных синтетических
данных. Отдельный эксплуатационный монотонный якорь, испытания физического
хранилища и независимая криптографическая экспертиза остаются открытыми.
