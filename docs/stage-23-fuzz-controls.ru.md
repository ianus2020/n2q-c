# Этап 23 — независимые параметры мутаций и границы ёмкости

При проверке harness этапа 22 обнаружены ограничения покрытия: номер бита был
связан с флагами режима, а однобайтовое смещение ограничивало мутации первыми
256 байтами. Аналогичное ограничение действовало на convergent capacity controls.
Это ошибки качества новых тестов, а не найденная уязвимость шифра.

Номер бита и 16-битное смещение теперь берутся отдельно от флагов профиля.
Ёмкости convergent также имеют отдельный 16-битный control. Корпус добавляет
каждый байт тега и все восемь вариантов бита по отдельности, первые/средние/последние
байты больших сообщений и ёмкости 0, plaintext_length−1, plaintext_length и
ciphertext_length−1. Полный декартов перебор байт/бит/ключ/сообщение не заявляется.

## Проверка

Linux aarch64, Clang 14.0.6, ASan/UBSan с fatal recovery controls; Rust
nightly-2026-10-18, cargo-fuzz 0.13.2. Свежий корпус, seed 20261019,
бюджет 2000 выполнений / 20 секунд на цель, вход до 4096 байт:

| Цель | Выполнения | Полные наборы свойств |
|---|---:|---:|
| C fireline | 2000 | отдельно не считаются |
| C n2qf | 2000 | отдельно не считаются |
| C siv | 2000 | отдельно не считаются |
| C modes_roundtrip | 2000 | 1951, все 8 вариантов |
| C convergent | 1199 | 1152, оба профиля |
| Rust frames | 2000 | отдельно не считаются |
| Rust n2qf | 2000 | отдельно не считаются |

Итого 13 199 выполнений. Convergent остановился по времени, а не достиг 2000;
libFuzzer зафиксировал 21 секунду. Ошибок санитайзеров, принятых повреждённых
сообщений и нарушений проверяемых свойств не обнаружено. Счётчики свойств входят
в число выполнений и к нему не прибавляются.

Отдельный контроль прочитал реальные corpus files: у всех вариантов присутствуют
8 bit choices, все байты тега пустого сообщения, смещения 0/середина/конец для
4046-байтного текста и convergent capacity boundaries, включая значения >255.
Проверены два verification-record tests, Python compilation и git diff.

Тестировался precommit snapshot с synthetic Git SHA; каждый хэш исходника в
summary сверен с рабочим деревом. Полный лог, corpus archive, controls и SHA-256
сохранены [в evidence](audit/2026-10-19-fuzz-controls/). Расширенный прогон выполняется
из следующего реального коммита. Это тесты реализации, а не доказательство
криптостойкости и не внешняя независимая экспертиза.
