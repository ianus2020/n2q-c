# Этап 29 — воспроизводимая инструкция запуска фронтенда

В README браузерного стенда оставалась команда `python3 -m http.server`, хотя
регрессионный набор проверяет CSP, `nosniff`, referrer policy и COOP/COEP в
ответах сервера. Следование инструкции приводило к FAIL в первой проверке
заголовков: стандартный сервер Python не выдаёт эти пять заголовков.

Команда заменена на существующий `python3 scripts/serve-web.py --port 8765`.
Пояснение указывает, что этот loopback test host выдаёт заголовки, проверяемые
браузерным набором. Настройки CI и сам сервер на этом этапе не менялись.

## Проверки

- Прежняя команда на отдельном loopback-порту: все пять проверенных заголовков
  отсутствуют, browser suite exit 1 при первой проверке CSP.
- Исправленная команда: все пять заголовков присутствуют, полный browser suite
  exit 0, включая регрессию этапа 28. Команда проверена с системным Python 3.9.6.
- Оба временных сервера остановлены после проверки. Production и сохранённый
  локальный стенд не изменялись.

[Evidence](audit/2026-10-20-browser-instructions/) содержит заголовки до/после,
журналы браузера, хэши README и тестовых входов, SHA256SUMS. Проверка относится
к инструкции локального запуска, а не к фактической конфигурации реального
HTTPS-хостинга.
