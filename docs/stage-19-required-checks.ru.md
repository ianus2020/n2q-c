# Этап 19 — обязательные проверки всех новых компонентов

GitHub protection main требовала только native/web/fuzz/dependencies, хотя
workflow уже содержал отдельные cryptanalysis, anchor и migration. Эти три
задания теперь добавлены в required status checks после их реального PASS
на `c556436`. Все проверки привязаны к GitHub Actions app_id=15368.

Перед PATCH прочитана текущая политика; существующие checks сохранены. После
изменения отдельный GET подтвердил strict=true и семь checks. Полное сравнение
before/after подтвердило, что другие поля защиты main не изменены: enforce
admins, запрет force-push/удаления и остальные параметры сохранены. Настройка
approving reviews остаётся 0; она не подменяет независимый внешний аудит.

[Снимок применяемой политики](main-protection-policy.json) обновлён.
[Проверенные публичные метаданные](audit/2026-10-19-required-checks.json)
не содержат токенов или пользовательских ключей. Это снимок настройки GitHub,
а не автоматически применяемая при checkout декларация.

Исходники этапов 16–18 сохраняют отдельные коммиты. На локальном стенде после
перезапуска с новым кодом verified HTTPS=200 и mTLS health=204; все Chromium
сценарии PASS. Сравнение логических counter rows и SHA-256 журнала подписанта
до/после подтвердило сохранение состояния. PKI/identity не пересоздавались.

Репозиторий остаётся private, PR №1 draft. Слияние, production deployment,
реальная миграция и изменение видимости на public не выполнялись.
