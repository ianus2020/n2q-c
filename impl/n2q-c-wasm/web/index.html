N2Q

Загрузка WASM…

Экспериментальный шифр без независимой криптографической экспертизы. Не используйте для реальных секретов. Обработка выполняется локально в браузере. Сохраните ключ и использованный AAD самостоятельно; для очистки формы нажмите «Очистить всё».

Пример работы

  1. Выберите N2Q-128 и Secure · 16 раундов, нажмите «Новый ключ» и сохраните его.
  2. В разделе «Шифрование» введите AAD demo:v1 и текст Привет 🌍, затем нажмите «Зашифровать».
  3. Нажмите «В поле дешифрования»: токен и AAD перенесутся вместе. Нажмите «Расшифровать» — результатом будет Привет 🌍.

При повторном шифровании создаётся новый случайный nonce, поэтому токен меняется. Стенд работает с текстовыми токенами nqc.; файловый контейнер N2QF и получение ключа из пароля доступны в отдельных инструментах проекта.

Параметры шифрования

N2Q-128: 32 hex-символа; N2Q-256: 64. Введите ключ без пробелов. Смена размера сохраняет ключ; «Новый ключ» заменяет его. Для этой формы нужен готовый ключ, а не пароль.

Nonce уже включён в токен; отдельно вводить его для дешифрования не требуется.

Шифрование

AAD хранится отдельно от токена и должен точно совпадать при дешифровании. Пустой AAD допустим.



Дешифрование
Для дешифрования нужны исходный ключ и тот же AAD. Размер схемы, профиль и nonce читаются из токена; выбор размера и профиля в верхних списках используется для шифрования, хэша и blind index.


Хэш и blind index
Хэш не требует ключа. Blind index использует ключ, выбранный размер и профиль; одинаковые данные при тех же параметрах дают одинаковый индекс. Результаты выводятся в hex: N2Q-128 — хэш 64 символа, индекс 32; N2Q-256 — хэш 128 символов, индекс 64.


Проверка реализации
Самопроверка не заменяет криптоанализ.


Без сохранения ключей в хранилищах браузера. Очистка удаляет поля и завершает worker; гарантированное стирание памяти JavaScript/WASM недоступно.
